# AI Career Guide

AI Career Guide is an academic Android mini-project built for Mobile Application Development coursework (IT305).

Description
- Simple rule-based career recommendation app for students.

Features
- Quiz-based career assessment
- Career list and details
- Save careers to local SQLite database
- Export career plan to internal storage
- SharedPreferences for student name and settings
- WebView for resources, email/map intents, notification reminder

Technology
- Java, XML, Android SDK, SQLite

How to run
- Import the project into Android Studio and build/run on an emulator or device.

Note
- This is a student-level project. Recommendations are rule-based and NOT a trained ML model.
